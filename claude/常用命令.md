**安装、卸载、检查**

```powershell
npm uninstall -g @anthropic-ai/claude-code		# 卸载

npm list -g @anthropic-ai/claude-code   		# 检查

npm install -g @anthropic-ai/claude-code@2.1.150	# 安装指定的版本

claude --version

# windows环境下设置“禁止自动更新”
[Environment]::SetEnvironmentVariable("DISABLE_AUTOUPDATER", "1", "User")	
$env:DISABLE_AUTOUPDATER	# 打开新窗口，输出“1”表示设置成功
```

**追溯对话**

```powershell
# 继续最近一次对话
claude --continue

# 选择历史对话
claude --resume
```
