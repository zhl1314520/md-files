- 默认启动（低权限）
- 中等权限启动

- 高权限启动
  - claude --permission-mode bypassPermissions

| 模式              | 文件修改 | shell命令 | 安全性 |
| ----------------- | -------- | --------- | ------ |
| default           | 询问     | 询问      | 高     |
| acceptEdits       | 自动     | 询问      | 中     |
| bypassPermissions | 自动     | 自动      | 低     |
