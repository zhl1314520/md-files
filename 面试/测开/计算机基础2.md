## 📌 HTTP缓存 / 缓存寿命 / 是否修改判断

> HTTP缓存分为**强缓存 + 协商缓存**

- 强缓存：通过 `Cache-Control / Expires` 控制
   👉 未过期直接用本地缓存，不请求服务器
- 协商缓存：通过 `Last-Modified / ETag`
   👉 向服务器确认是否修改

👉 是否修改判断：

- `Last-Modified + If-Modified-Since`
- `ETag + If-None-Match`

👉 一句话：

> 强缓存看“过没过期”，协商缓存看“变没变”

## 📌 HTTP协议 / 数据段 / 无状态 / HTTPS / IP分类 / 分层 / 长短连接

## HTTP协议

> 基于TCP的应用层协议，用于客户端和服务器通信

## HTTP报文结构

- 请求行 / 状态行
- 请求头 / 响应头
- 空行
- 请求体 / 响应体

------

## 无状态原因

> 每次请求独立，服务器不保存客户端状态（靠cookie/session解决）

------

## HTTP vs HTTPS

- HTTP：明文、不安全
- HTTPS：SSL/TLS加密、安全、有证书

------

## IP地址分类（了解即可）

- A类：大网络
- B类：中等

## 长连接 vs 短连接

- 短连接：请求一次断开（HTTP1.0）

## 📌手写代码（日志提取+排序）

Python示例（面试够用）：

```
import re

logs = [
    "id=1 date=2024-01-02",
    "id=2 date=2023-12-01"
]

dates = []

for line in logs:
    match = re.search(r"date=(\S+)", line)
    if match:
        dates.append(match.group(1))

dates.sort()

print(dates)
```

👉 核心：

> 正则提取 + 排序
