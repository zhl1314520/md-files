在 Python 中，变量名前面加下划线（如 `_variable`）的含义，主要取决于它**出现的位置**（在 `__init__` 中、在类里面但不在方法内、或者在类外面）。

以下是这三种情况下 `_变量` 的具体含义和作用：

### 1. 在 `__init__` 函数中 (`self._variable`)

- **表示什么**：**实例属性（Protected Protected Attribute）**。

- **详细解释**：

  - 它是属于该类某个具体对象（实例）的变量。只要对象存在，它就一直存在。
  - **单下划线前缀 (`_`) 是一种约定**，用来告诉其他开发者：“这是内部属性，请尽量不要在类的外部直接访问或修改它”。

- **代码示例**：

  ```python
  class User:
      def __init__(self, name):
          self._name = name  # 实例属性，外部虽然能访问，但最好别改
  ```

### 2. 在类里面、方法外面 (`_variable = ...`)

- **表示什么**：**类属性（Class Attribute）** 或 **类级别的常量/共享变量**。

- **详细解释**：

  - 它不属于某一个具体对象，而是**属于整个类所有**。该类的所有实例共享这一个变量。
  - 同样，单下划线开头代表这是一个**内部类属性**，主要给类内部的方法使用，或者作为配置项。

- **代码示例**：

  ```python
  class APIClient:
      _TIMEOUT = 30  # 类属性（内部常量），所有 APIClient 的实例都可以共享它
  
      def connect(self):
          print(f"连接超时时间: {self._TIMEOUT}")
  ```

### 3. 在类外面（模块级别 / 全局变量）

- **表示什么**：**模块内私有变量（Internal Use Module-Level Variable）**。

- **详细解释**：

  - 它是一个定义在函数和类之外的全局变量。
  - 当其他模块使用 `from module import *` 导入时，**单下划线开头的变量不会被导入**。这起到了保护模块内部实现、避免命名污染的作用。

- **代码示例**：

  ```python
  # config.py 文件中
  _DB_PASSWORD = "secret_password"  # 模块内部变量
  PUBLIC_URL = "https://api.com"    # 公开变量
  ```
