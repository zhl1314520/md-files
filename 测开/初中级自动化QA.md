# ✅ 一、必须掌握（初/中级自动化实习生）

## 1️⃣ 编程基础（核心门槛）

👉 推荐语言：Python

必须会：

- 基础语法（函数、类、异常）
- 常用数据结构（list / dict / set）
- 文件操作（读写日志、配置）
- 简单面向对象（类封装）

👉 能做到：

- 能写自动化脚本（不是只会 copy）

------

## 2️⃣ Web基础（UI自动化前提）

必须懂：

- HTML（结构）
- CSS（选择器）
- JavaScript（基本理解）

重点理解：
 👉 **DOM（这是核心）**

👉 能做到：

- 看懂页面结构
- 能自己写 xpath / css

------

## 3️⃣ UI 自动化（重点🔥）

核心工具：

- Selenium（必须）

必须掌握：

- 元素定位（id / css / xpath）
- 显式等待（重点）
- iframe / 多窗口切换
- alert 处理
- 表单操作（输入、上传）

👉 能做到：

- 独立写一个登录 + 业务流程自动化脚本

------

## 4️⃣ 自动化测试框架（非常重要）

推荐：

- pytest（主流）

必须掌握：

- fixture（重点）
- 参数化（parametrize）
- conftest.py
- 用例组织（目录结构）

👉 能做到：

- 写一个“像样的项目结构”

------

## 5️⃣ 接口测试（必备技能🔥）

工具：

- requests + pytest

必须掌握：

- GET / POST
- header / token
- JSON 解析
- 接口关联（登录 → token → 其他接口）

👉 能做到：

- 写接口自动化用例

------

## 6️⃣ 数据库（基础）

至少会：

- MySQL 基本 SQL
  - select / insert / update

👉 能做到：

- 校验接口数据是否正确

------

## 7️⃣ Linux（基础）

必须会：

- cd / ls / grep / tail
- 查看日志

👉 能做到：

- 能在服务器排查问题

------

## 8️⃣ Git（必须）

必须会：

- git clone
- git pull / push
- git commit
- git log

👉 能做到：

- 管理代码版本（面试必问）

------

## 9️⃣ 自动化基础设计思想（加分但建议必会）

👉 **POM（Page Object Model）**

必须理解：

- 页面封装
- 元素与操作分离

👉 能做到：

- 不写“屎山脚本”

------

# 🎯 二、你达到这个水平 = 能过初级面试

👉 能说清：

- Selenium 原理（简单版）
- pytest 怎么用
- UI 自动化怎么做
- 接口自动化流程

------

# 🚀 三、加分项（拉开差距🔥）

## 1️⃣ 自动化框架设计（中级关键）

能讲：

- 分层结构（page / test / utils）
- 配置管理（yaml / ini）
- 日志（logging）
- 报告（Allure）

👉 面试直接加分

------

## 2️⃣ CI/CD（非常加分🔥）

工具：

- Jenkins

理解：

- 自动跑测试
- 自动生成报告

👉 能说出流程：

```
代码提交 → Jenkins → 执行自动化 → 报告
```

------

## 3️⃣ 接口自动化进阶

会：

- session 复用
- token 自动处理
- 数据驱动（yaml/json）
- mock（简单了解）

------

## 4️⃣ 性能测试（加分）

工具：

- JMeter

理解：

- QPS / TPS
- 压测流程

------

## 5️⃣ Docker（加分）

👉 知道：

- 容器是什么
- 能跑一个服务

------

## 6️⃣ 前端框架理解（加分）

👉 知道：

- Vue / React 是什么
- 为什么元素难定位（动态渲染）

------

## 7️⃣ Selenium 进阶（很加分）

会：

- headless
- 自动截图
- 执行 JS
- 处理复杂定位

------

## 8️⃣ 代码能力（关键分水岭）

👉 能做到：

- 写工具函数
- 封装公共方法
- 代码结构清晰

------

# ❌ 面试常见“扣分点”

很多人挂在这里：

- 只会写脚本，不会设计框架
- 不会接口测试
- 不会用 pytest
- 不懂 DOM
- Git 不熟

------

# 🧠 最终总结（面试官视角）

👉 初级看：

- 会不会 Selenium + pytest
- 能不能写用例

👉 中级看：

- 会不会框架设计
- 会不会接口自动化
- 稳定性怎么保证

👉 高级看：

- 架构能力
- CI/CD
- 测试体系
