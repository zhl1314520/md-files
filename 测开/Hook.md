# Hook 

## 定义

> Hook（钩子）**本质上是一种**事件驱动的编程机制
> 简单来说，就是在程序运行的某个特定时刻（或者特定事件发生时），**“挂载”并自动执行**的一段自定义代码

## 例子

> 电商平台：
>
> - **核心程序**：电商平台处理订单的流程（下单 -> 付款 -> 发货）
> - **Hook（钩子）**：你在“付款成功”这个节点设置了一个钩子，挂载了一段发短信的代码。当付款完成后，系统会自动“勾”住这个事件，顺便执行你的发短信逻辑，而不需要修改电商平台原本的核心代码

## 好处

> **解耦与扩展**：允许开发者在不修改第三方库或框架源码的前提下，插入自定义的业务逻辑（比如 Django 或    Flask 框架中的请求拦截器）
>
> **插件化开发**：方便为主程序添加各种插件功能

```python
# 1. 定义一个核心函数（预留了 Hook 的位置）
def do_work(hook_function=None):
    print("1. 开始执行核心任务...")
    
    # 如果挂载了钩子，就在这里触发它
    if hook_function:
        hook_function()
        
    print("3. 核心任务结束。")

# 2. 定义我们的自定义钩子函数
my_hook = lambda: print("   --> [Hook 触发] 执行额外的自定义操作！")

# 3. 运行程序并挂载钩子
do_work(hook_function=my_hook)
```
