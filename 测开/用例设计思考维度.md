**功能测试**

```
验证业务功能是否符合需求，是测试用例设计的核心

正常登录、退出登录
注册、修改密码、找回密码
CRUD
角色权限、业务流程、数据状态变化
```

**UI 测试**

```
验证页面展示、交互行为和布局是否正确

页面元素是否完整、显示是否正常
按钮、输入框、下拉框能否正常操作
页面布局、字体、颜色、对齐
弹窗、提示信息、加载状态
不同分辨率下的布局表现
```

**接口测试**

```
验证前后端接口的请求、响应和业务逻辑

请求参数正确、缺失、为空、类型错误
HTTP 状态码、响应数据结构
数据库数据是否正确新增或修改
Token、身份认证、权限控制
重复请求、接口异常、超时处理
```

**兼容性测试**

```
验证软件在不同环境下能否正常运行

不同浏览器：Chrome、Edge、Firefox
不同操作系统：Windows、Android、iOS
不同手机型号、分辨率、系统版本
不同网络环境
```

**性能测试**

```
验证系统在不同负载下的响应和稳定性

响应时间是否达标
并发用户量、吞吐量
压力测试、负载测试
长时间运行是否稳定
高负载下错误率、资源占用情况
```

**安全测试**

```
验证系统能否抵御常见安全风险

未登录是否可以访问受保护页面或接口
不同角色能否越权访问数据
SQL 注入、XSS 等常见风险
密码、Token 等敏感信息的保护
登录失败次数限制、会话过期处理
```

**异常测试**

```
验证系统面对异常输入和异常环境时的表现

输入为空、超长字符、非法字符
网络断开、请求超时、服务器错误
重复提交、连续点击
数据不存在、数据冲突
异常发生后能否恢复，数据是否一致
```
